Six Core Functions of Modern Operating Systems

Chapter 8 Learning Objectives
1. Process Management

Creates, schedules, and terminates processes & threads; handles context switching, deadlocks, and inter-process communication (IPC).

2. Memory Management

Gives each process an isolated virtual address space, maps pages to physical RAM frames, and swaps inactive pages to disk.

3. File Systems

Organizes raw storage blocks into hierarchical directories and files with journaling and metadata (NTFS, APFS, ext4, Btrfs).

4. Access & Permissions

Enforces multi-user isolation via Access Control Lists (ACLs) or POSIX `rwx` bits (`chmod`) so untrusted code cannot alter system files.

5. Device & I/O Control

Communicates with GPUs, keyboards, USBs, and network cards via hardware interrupts, DMA channels, and kernel device drivers.

6. Security & Sandboxing

Protects data via full-disk encryption (BitLocker, FileVault, LUKS), secure boot, sandboxing, and mandatory access controls.
